  remain explicit release gates; mock evidence is not those claims.
- [x] Handoff/status saved before selective commit and evidence publication/closure.

See `docs/GENERATION_ADMISSION.md` for the exact policy and recovery contract.
`GENERATION_ADMISSION_POLICY` is opt-in to preserve existing local startup. A
funded classroom release requires its evidenced policy. Missing policy means no
budget protection; invalid configured policy fails startup. All local workers and
owners must share one persistent dedicated SQLite file/policy. This is not a
multi-host/DSQL ledger implementation. The port is replaceable; no AWS dependency
was added. Background submission bounds are per process; actual generation shares
its ledger across local processes. Existing HTTP/threadpool/parser buffering and
non-generation costs are outside this admission seam.

Unknown usage/hidden retries retain the entire per-call ceiling. Only complete,
exactly priced input/output/cache meters, known model-call count and zero SDK
retries can refund unused allowance. Operator ceiling evidence must include all
allowed roles/models, context/output caps and SDK/runtime retry exposure. Known
cost overruns remain charged and block **both** fresh and already queued calls.
Expired running invokes keep charge and capacity: expiry is not proof an external
call stopped. The original worker may settle; orphan recovery requires all workers
stopped, a new SQLite backup and explicit confirmation. Recovery never refunds
invoked charges or clears an overrun hold. No student schema or data migration.
Preserve this ledger across rollback; stop funded generation before reverting.
