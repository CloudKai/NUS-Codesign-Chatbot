# Co-design student companion

<!-- impeccable:product-schema 1 -->

## Platform
web

## Users and purpose
CDE2300 students ask lecture questions and develop a design project with a
critical-thinking coach. The companion preserves notebooks, source evidence,
conversation history and student-authored project work across sessions.

## Mechanism
One backend-owned five-stage workflow supports problem identification, concept
generation, design specification, ethics and critical thinking, and reflection.
Students explicitly confirm recommended stage transitions. Lecture help does not
advance the project. Student work is not graded by this tool.

## Confirmed design commitments
The React redesign follows the user's ChatGPT, Gemini and Codex references:
collapsible left navigation, central chat, right critical-thinking/progression.
The user selected both small reasoning challenges and saved progress/next steps.
Preserve Streamlit, source/citation actions, existing account/data boundaries,
draft recovery, preferences, and accessibility. Do not fabricate achievements.

## Constraints and open decisions
Local mock preview only; no paid model calls or deployment authorized. Image
generation is a requested possible future tool, not a working capability.
Student data location requirements and production hosting remain undecided.
